# 🛡️ DevPortal - 跨平台軍規級 AES-256 加密技術手冊門戶系統

`DevPortal` 是一款專為開發團隊與獨立開發者設計的**廣播級技術文檔整合與安全部署系統**。它能自動掃描、編譯多個獨立子專案的開發手冊，將其重構為頂級視覺美學的單頁手冊，並以 **AES-256 軍規級密碼學演算法** 進行全網頁靜態加密封裝。

系統完美適應**跨環境開發**（例如公司電腦 `M:\` 與家中主電腦 `E:\`），並解耦為極速的二步驟部署發布管線，支援無縫託管至 GitHub Pages，實現「源碼完全隔離、線上安全查閱」的極致體驗。

---

## 🚀 核心系統特點

### 1. 跨電腦「環境自適應動態路徑」
系統捨棄了所有硬編碼（Hardcoded）絕對路徑，採用動態回溯偵測：
*   **PowerShell 腳本**：自動以 `$PSScriptRoot` 為基準向上推導，自動適應公司與家中的硬碟代號與目錄結構。
*   **Python 編譯器**：自動通過 `os.path.abspath` 動態向上遞迴定位，完美尋找 `KCG即時翻譯` 的基礎 HTML 模板。

### 2. 門戶超連結「子專案資料夾動態映射」
為了解決兩台電腦間子專案資料夾命名不同（中文 ↔ 英文）導致的網頁超連結失效問題，系統內建動態映射字典，不論您的本機資料夾名稱是中文還是英文，編譯時都會**自動統一命名為門戶預期的標準英文 URL 目錄**輸出（例如將 `問答小程式` 自動重新命名為 `qa-mini-program` 並加密輸出）。

### 3. 分離式「極速二步驟發布管線」
將編譯與推送任務徹底解耦，大幅提升工作流效率：
*   **第一步：本地編譯與安全加密 (`準備.bat`)**
    *   全自動呼叫各子專案 Python 編譯器 ➔ 同步至發布目錄 ➔ 物理清除未加密原始碼 ➔ 執行 StatiCrypt AES-256 靜態網頁加密。
*   **第二步：一鍵極速上傳至 GitHub (`上傳.bat`)**
    *   **僅負責 Git 傳輸**（不再重複執行編譯加密），自動偵測分支並以不到 1 秒的閃電速度安全推送至 GitHub Pages。

### 4. 殘留防呆「自動清空編譯目錄」
每次編譯啟動時，系統會自動物理清空 `projects/` 目錄，徹底解決因重新命名產生的歷史遺留資料夾問題，**防止 Staticrypt 對舊檔案進行重複二次加密**，將總體積從 115MB 大幅瘦身至 **1.78MB**（體積縮減 98%），保證網頁加載速度與 Git 推送效率。

## 🎨 門戶首頁視覺美學

門戶首頁（`src/index.html`）採用現代頂級網頁美學設計：
*   **高質感毛玻璃擬態 (Glassmorphism)**：高對比暗黑色調搭配 `backdrop-filter` 模糊，營造極具未來感的視覺檔次。
*   **霓虹發光邊框特效**：為每個專案配置專屬的自定義霓虹主題色（如 LiveVote 青色、Wrestling 金黃色），滑鼠懸停時觸發平滑上升動畫與陰影漫延。
*   **全繁體中文功能直覺化**：所有卡片標題皆本地化為功能直覺的中文名稱，極具商用與展示檔次。

## 🛠️ 核心技術棧

*   **密碼學核心**：[StatiCrypt](https://github.com/mrstdg/staticrypt) (基於 Stanford JavaScript Crypto Library - SJCL)，提供 **AES-256 PBKDF2** 高強度網頁加密。
*   **後端與自動化管線**：
    *   **PowerShell 5.1+**：負責多路徑自適應、資料夾清理、自動映射、檔案流搬移與 Staticrypt CLI 調度。
    *   **Python 3.x**：各子專案的文檔編譯器，解析 Markdown，動態注入 JSON 數據並實現 Rebranding客製化替換。
*   **前端技術**：HTML5, Vanilla CSS (CSS 變數、Flexbox, CSS Grid 響應式佈局), Google Fonts (Outfit, JetBrains Mono, Noto Sans TC), FontAwesome 6 圖示庫。
*   **流程圖渲染**：Mermaid.js (單頁整合動態渲染)。

## 🔒 安全架構與去中心化獨立密碼保護

### 1. 去中心化獨立專案密碼設定 (`password.txt`)
為了讓各個專案在單獨發布或本地閱讀時，能夠擁有自己獨立的密碼防護，系統設計了去中心化的密碼管理方式：
*   **專案密碼檔**：各專案可直接在其 `docs` 資料夾下，新增一個 `password.txt` 的純文字檔案（寫入該專案的專屬密碼，如 `basketball123`）。
*   **自適應打包讀取**：主門戶打包腳本 `build.ps1` 執行時，會自動掃描並讀取各專案的 `docs\password.txt` 作為該專案手冊的加密金鑰。若偵測不到，則以 `"123456"` 備用密碼作為 Fallback 預設保護。
*   **無密碼公開主門戶**：主目錄下的入口門戶 `docs-portal/index.html` 改為 **完全免密碼公開直接開啟**。使用者可自由點選專案卡片，點選後會自動導向至該專案已加密的頁面，並要求輸入該專案專屬的技術手冊密碼。

### 2. 物理隔離與同步過濾 (安全防護)
*   **源碼完全不入庫**：您各個子專案的原始技術手冊（`.md` 原始檔）與編譯代碼，全部存放在 `docs-portal` 倉庫之外。門戶 Git 倉庫中完全不存在任何未加密的 Markdown 原始檔案。
*   **直接複製加密頁面 (極速且防外洩)**：子專案的本地啟動器在同步至整合門戶時，**只會複製加密後的 HTML 檔案並改名**，同時僅同步 `assets/` 或 `images/` 等靜態資源。原始 Markdown 原始碼、`.py` 編譯腳本與 `password.txt` 密碼明文**從源頭上根本不會被複製到門戶目錄中**，徹底消除明文密碼與原始碼外洩的風險！

## 💡 使用指南

### 1. 全域一鍵發布模式（雙擊門戶下的 `準備.bat`）
當您準備把所有專案的技術手冊一次發布上線至 GitHub Pages 時：
*   **自動化流程**：直接雙擊執行門戶底下的 **`準備.bat`**。
*   **全自動免打擾**：系統將自動於背景執行所有子專案的 Python 編譯，並自動掃描讀取各專案下的 `password.txt` 完成 AES-256 加密。**整個過程不需要您手動輸入任何入口密碼**，即在數秒內一鍵完成所有專案的打包與安全封裝！
*   **發布上線**：打包完成後，雙擊執行 **`上傳.bat`**，Git 傳輸管線將在不到一秒的閃電速度下將加密手冊推送至您的 GitHub Pages。

### 2. 單一專案本地開發模式（雙擊專案下的 `打開開發者文件.bat`）
當您平常在單一子專案中撰寫或修改手冊文件時：
*   **編譯與加密**：直接雙擊執行該專案根目錄下的 **`打開開發者文件.bat`**。
*   **門戶即時同步連動**：批次檔會自動進行編譯與 AES-256 加密，並在本地端開啟已加密的手冊。同時，它會自動偵測鄰近目錄是否存在 `..\docs-portal`。若存在，會**直接以最安全的方式將加密網頁與靜態資源拷貝更新至整合門戶**，實現即時手冊連動！
*   **無縫 Git 跨電腦協作防呆 (Safeguard Skip)**：若專案是透過 Git 拉取到其他電腦編輯，且該電腦**沒有安裝或放置 `docs-portal` 整合門戶**，批次檔會自動顯示「`💡 [提示] 未在鄰近目錄偵測到 docs-portal 整合門戶，已跳過同步。`」，並**自動略過同步步驟安全繼續**，提供最優異的跨電腦協作體驗！
